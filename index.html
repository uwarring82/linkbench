Access and backbone
Home Wi-Fi, DSL or cellular leads to the provider’s access network. Edge and core IP routers forward packets. Providers may exchange traffic at an internet exchange or through a private connection. G.652 and low-loss G.654.E are examples of terrestrial single-mode fiber.
Landing stations and subsea fiber
Landing stations connect land networks to submarine optical systems. Long-haul systems can use low-loss single-mode fiber such as G.654. Optical repeaters amplify signals and normally stay invisible to IP traceroute.
How to check your route
Trace from your own device to the exact test server to see responding outward hops. M-Lab archives server-side traces that can be linked by connection UUID. A trace can support a metro or carrier inference, while fiber type, cable geometry and router model require operator evidence.

Measurement method

What the numbers mean

Goodput counts application payload bytes over the browser’s elapsed request time. Idle and loaded latency measure small HTTPS requests. A result describes the full path to the selected target and includes browser and server overhead.

Cloudflare demo and pilot profiles

The live demo uses Cloudflare’s public edge and a small payload budget. The edge can change between runs and lacks the pilot’s responder logs. The pilot profiles require controlled responders, record address family and HTTP version, and budget 214 MB per target per run. Loaded results require at least four probes. Probe timeouts contribute a 5,000 ms capped value.

Worldwide NDT7 tests

Downloads run together, followed by uploads together. Each site uses M-Lab’s NDT7 protocol. Linkbench shows download goodput from received bytes, upload goodput from server receipts when available, with labeled server TCP rates or browser estimates as fallbacks, and minimum server TCP RTT when available. TCP RTT and HTTPS request latency measure different things. Compare across runs with the same site selection and note any server changes.

How to compare DSL and cellular

Use the same target, browser, and local interface. Keep the VPN setting fixed. Enter a unique block label for each paired window and reuse it for the two uplinks. Six daytime and evening blocks form the Freiburg pilot. A win requires at least 20 ms and 25% lower upload-loaded latency in five of six eligible blocks.
